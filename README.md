# Diamond Focus

A baseball-themed productivity app that turns your daily tasks into a 9-inning game.

## Features

- Defense/Offense task system (complete 3 defensive tasks to unlock offense)
- 9-inning day structure (Morning, Afternoon, Evening)
- Baseball diamond progress visualization
- Dugout Notes panel
- Relief Pitcher break timer
- Energy management (Scouting Report)
- Baseball card task view with flip animations

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS + shadcn/ui
- Framer Motion
- localStorage persistence

## Development

```sh
npm install
npm run dev
```
